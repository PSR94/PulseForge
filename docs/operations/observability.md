# Observability

PulseForge emits structured JSON request logs and Prometheus metrics for:

- documents processed by stage/source
- processing failures by stage
- LLM latency and estimated cost dimensions
- event clusters created
- entity-resolution confidence
- signals generated by type/severity
- source ingestion delay
- active SSE clients

`/api/v1/metrics` exposes Prometheus format. Set `PULSEFORGE_OTLP_ENDPOINT` to export traces through the
OpenTelemetry HTTP exporter.
